## ARCHITECTUUR WIJZIGINGEN

### Nieuw principe: Engine-side Relevance Selection
```
User message → Nano (themes) → Relevance Selector → buildPersonalClinicalContext
                                    ↓
                         theme_matched: alleen relevante schemas/modes
                         direct_question: ALLES met "list ALL" instructie
                         no_match: ALLES (veilige fallback)
```

### Nieuw principe: Presence Labels (vervangt confidence numbers)
```
confidence >= 0.8  → "zeer sterk aanwezig"
confidence >= 0.5  → "aanwezig"
confidence < 0.5   → "minder dominant"
healthy_adult      → "aanwezig maar mag sterker worden"
```

### Nieuw principe: No Slice Limits
- Alle gevonden schemas/modes/triggers/etc gaan naar GPT
- MAX_CHARS budget = 4000 (was 2000)
- Engine selecteert op relevantie, niet op willekeurige max
